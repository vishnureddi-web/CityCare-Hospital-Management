# CityCare Hospital Management System

## Overview
CityCare is a responsive hospital management web application that allows patients to book appointments, manage profiles, and interact with doctors online.

## Features
- Patient Registration & Login
- Firebase Authentication
- Appointment Booking
- Admin Dashboard
- Razorpay Payment Integration
- Responsive Design

## Tech Stack
- HTML
- CSS
- JavaScript
- Firebase
- Firestore
- Razorpay API

## Project Modules
- Patient Dashboard
- Doctor Listing
- Appointment Booking
- Admin Panel
- User Authentication
